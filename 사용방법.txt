OOS (Only One Sentence) — 사용·실행 안내
========================================

1. 실행 방법
-----------
A) 기본 UI만 (AI 없음)
  1) 탐색기에서 OOS 폴더를 연다
  2) index.html 파일을 더블클릭한다
  3) Chrome / Edge 등 브라우저에서 열린다

B) Gemini AI 쓰기 (연습 손님 멘트 · 회화/단어) — 브라우저 CDN
  ※ Node 없이 @google/genai(esm.sh) + js/gemini.js
  ※ 키는 .env 의 GEMINI_API_KEY 를 브라우저가 fetch 합니다 (로컬 서버 필요)
  1) .env 에 GEMINI_API_KEY=... 가 있는지 확인
  2) VS Code Live Server 등으로 OOS 폴더를 http로 연다
     (index.html 더블클릭 file:// 로는 .env / CDN 이 막힐 수 있음)
  3) 연습 시작 → 손님 첫 멘트 AI 생성 (실패 시 로컬 멘트)
  4) F12 콘솔에서 회화/단어 바로 불러오기:
     await OOS_GEMINI.loadDialogue("카페", "품절")
     await OOS_GEMINI.loadVocab("편의점", "위치 안내")
     await OOS_GEMINI.generateJobEnglish({ industry: "식당", situation: "주문", kind: "dialogue" })

모바일처럼 보려면 브라우저 창을 좁히거나,
개발자 도구(F12) → 기기 툴바 아이콘으로 스마트폰 크기를 고른다.


2. 폴더 구조
-----------
OOS/
  index.html          ← 시작 화면
  styles.css          ← 디자인
  server.mjs          ← Gemini 프록시 + 정적 서버 (키는 여기만)
  .env                ← GEMINI_API_KEY (절대 공개/커밋 금지)
  .env.example        ← 키 자리 예시
  js/
    data.js           ← 상황·영어 문장
    storage.js        ← 기기 저장
    speech.js         ← 발음 듣기
    gemini.js         ← 프론트 Gemini 연동 (키 없음, /api/gemini 호출)
    practice-demo.js  ← 연습 (Gemini 손님 멘트 → 실패 시 로컬 폴백)
    app.js            ← 화면·버튼 동작
  커서_프롬프트.txt
  사용방법.txt


3. 문장·상황 수정하는 법
-----------------------
js/data.js 파일을 메모장이나 Cursor로 연다.
SITUATIONS 배열 안에서 en(영어), ko(한국어 뜻), choices(손님 뜻 선택지)를 고친다.
저장 후 브라우저를 새로고침(F5)하면 반영된다.

업종을 추가하려면:
- INDUSTRIES에 { id, label, icon } 추가
- SITUATIONS에 industries: ["새id"] 인 상황을 추가


4. 실제 AI를 연습에 연결하려면 (나중)
------------------------------------
지금은 js/practice-demo.js 의 고정 데모만 동작합니다.
연결 시 권장:
- API 키는 서버(또는 서버리스 함수)에만 두고, 브라우저/저장소에 넣지 말 것
- practice-demo.js 의 MODE / submitAnswerAI 만 교체하면 화면(app.js)은 그대로 둬도 됨
- AI 장애 시에도 근무 탭 응대는 그대로 쓰이게 유지

6. 추천 테스트 순서
------------------
1) 카페 선택 → 홈에 공통 + 카페 전용만 보이는지
2) 「음료 옵션 확인」→ 선택지 따라 다음 문장으로 이동
3) 「못 알아들었어요」→ 되묻기 / 담당자 확인
4) 즐겨찾기 → 새로고침 후에도 유지
5) 설정에서 편의점으로 변경 → 홈 상황이 바뀌는지
6) 식당 「인원·좌석」→ 인원 미입력 시 안전한 문장, 입력 후 반영
7) 크게 보여주기 → 닫기로 복귀
8) 연습 탭 → 데모 배너 확인 → 답변 보내기 → 예시만 나오는지
9) 설정 → 초기화 → 업종 선택 화면으로 돌아가는지
